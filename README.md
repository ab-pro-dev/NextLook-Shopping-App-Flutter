# NextLook — Clothing Shopping App

Monorepo for the NextLook mobile shopping experience.

## Project Structure

| Directory | Description |
|-----------|-------------|
| `nextlook/` | Flutter mobile app (Android & iOS) |
| `backend/`  | Node.js + Express + Prisma API |
| _(future)_ | `admin_dashboard/` — Admin web dashboard |

## Getting Started

```bash
# Flutter app
cd nextlook && flutter pub get && flutter run

# Backend
cd backend && npm install && npm run dev
```
